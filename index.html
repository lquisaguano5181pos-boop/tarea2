Arquitectura

La arquitectura de computadores describe cómo se organizan sus componentes para ejecutar instrucciones, almacenar información y procesar datos con precisión.

Módulo 1

Arquitectura y Estructura de Computadores

La arquitectura de computadores estudia cómo se organiza una máquina para interpretar instrucciones, realizar cálculos, acceder a la memoria y coordinar sus elementos. Es fundamental para comprender no solo el funcionamiento del equipo, sino también la forma en que la evidencia digital puede ser capturada y analizada.

Componentes principales de la CPU

🧮

ALU — Unidad Aritmético-Lógica

Realiza operaciones matemáticas y lógicas como suma, resta, comparación y validación de condiciones.

🎛️

UC — Unidad de Control

Coordina cada instrucción, decide qué componente debe actuar y sincroniza la ejecución.

⚡

Registros

Almacenan temporalmente instrucciones, datos y direcciones que la CPU necesita acceder de forma inmediata.

ALU — Unidad Aritmético-Lógica

La ALU es la parte de la CPU encargada de ejecutar cálculos y comparaciones. Es esencial porque cada operación que realiza un computador, desde abrir un archivo hasta validar una contraseña, termina pasando por esta unidad.

  • Permite sumar, restar, comparar, evaluar condiciones y realizar operaciones binarias.
  • Los resultados se envían a registros o a la memoria según la instrucción.
  • Es una de las piezas centales del procesamiento digital.

Dirección IP vs Dirección MAC

Dirección IP

Es una dirección lógica que identifica un dispositivo dentro de una red.

192.168.1.10
  • Puede cambiar según la configuración.
  • Se usa para enrutar paquetes.

Dirección MAC

Es una dirección física asociada a la interfaz de red del dispositivo.

00:1A:2B:3C:4D:5E
  • Es única dentro de la capa local.
  • Se usa para identificar la interfaz de red.

Topologías de red

Estrella

       PC
        |
PC — SWITCH — PC
        |
       PC

Facilita la gestión y el diagnóstico, pero depende mucho del switch central.

Anillo

PC → PC → PC
↑         ↓
← ← ← ← ←

Las señales viajan en secuencia; fallas pueden afectar a toda la red si se interrumpe el anillo.

Bus

PC   PC   PC   PC
 |    |    |    |
====================
      Bus

Simple y económico, pero menos tolerante a fallos y con más colisiones.

Módulo 3

Aplicación en la Investigación de Ciberdelitos

En una investigación de ciberdelitos, comprender cómo funcionan la memoria, el procesador y las redes permite interpretar correctamente las evidencias digitales y establecer qué información pudo estar disponible durante un incidente.

Importancia de la RAM

La RAM puede contener evidencia volátil: procesos activos, conexiones de red, archivos temporales y datos útiles durante un incidente antes de que se borren.

Computador encendido ↓ RAM ↓ Procesos + conexiones + datos temporales ↓ Posible evidencia volátil

Importancia de los registros

Los registros reflejan instrucciones, direcciones y estados de procesamiento actual del sistema, ayudando a reconstruir qué estaba ocurriendo de forma inmediata.

Importancia del tráfico de red

El tráfico de red muestra comunicaciones, protocolos y destinos implicados en una actividad, aportando contexto sobre origen, destino y posible exfiltración.

Dispositivo A ↓ Tráfico ↓ Red ↓ Dispositivo B

Analizar diferentes fuentes de evidencia permite construir una visión más completa de lo ocurrido.

Conclusiones

Ideas clave

1. Comprender la máquina

La arquitectura del computador explica cómo se procesan instrucciones, datos y señales.

2. Entender la comunicación

Las redes muestran cómo se transmiten y gestionan los datos entre dispositivos.

3. Analizar evidencia

La memoria, registros y tráfico aportan información complementaria para una investigación.
